# Taller Knuth – Universidad del Rosario

## ¿Qué es el Taller Knuth?

El **Taller Knuth** es una iniciativa abierta de aprendizaje creada para que **cualquier persona**, sin necesidad de conocimientos previos en programación, pueda **aprender a interactuar con datos, crear aplicaciones web y desarrollar pensamiento computacional**.

Su nombre rinde homenaje a **Donald Knuth**, uno de los pioneros de la ciencia de la computación, autor de *The Art of Computer Programming*.

El objetivo del taller es fomentar la **curiosidad, la exploración práctica y el aprendizaje colaborativo**, acercando el mundo de la programación y el análisis de datos a estudiantes, profesionales y entusiastas de todas las áreas.

---

## ¿A quién va dirigido?

* Personas sin experiencia previa en programación.
* Estudiantes de pregrado o posgrado de cualquier disciplina.
* Profesionales interesados en usar los datos para tomar decisiones o automatizar procesos.
* Quienes quieran crear sus primeras aplicaciones web o visualizaciones interactivas.

No necesitas saber programar: **comenzamos desde cero**.

---

## Estructura del Taller

El ciclo **Agosto – Noviembre 2025** combina dos lenguajes de programación fundamentales:

| Lenguaje   | Enfoque principal                     |
| ---------- | ------------------------------------- |
| **R**      | Análisis y visualización de datos     |
| **Python** | Programación general y desarrollo web |

Cada sesión está diseñada para ser **autónoma y práctica**, permitiendo seguir el ritmo propio y revisar los materiales grabados.

## Temas que abordamos

| Eje                                 | Contenido                                              |
| ----------------------------------- | ------------------------------------------------------ |
| **Programación básica**             | Variables, estructuras de control, funciones y objetos |
| **Estructuras de datos**            | Listas, data frames y diccionarios                     |
| **Visualización**                   | Gráficas con *ggplot2* y *matplotlib*                  |
| **Importación y limpieza de datos** | Lectura desde archivos CSV, Excel o APIs               |
| **Desarrollo web**                  | Introducción a *Flask* para crear apps interactivas    |
| **Pensamiento computacional**       | Cómo estructurar problemas y soluciones con código     |
